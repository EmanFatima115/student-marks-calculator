# Student Marks Calculator

## Description

A simple Python program to calculate total and average marks.

## Features

- Takes student's name as input
- Takes marks of three subjects
- Calculates total marks
- Calculates average marks

## How to Run

1. Make sure Python is installed.
2. Run the `student_marks_calculator.py` file.
3. Enter your name and marks when asked.

## Example Output

Student Name = Eman
Total Marks = 245
Average Marks = 81.67
